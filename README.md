# senior-project

## About the dataset

This dataset combines inertial and visual sensor data to support multimodal recognition of swimming strokes. It contains 2010 rows with readings from 10 inertial measurement units (IMUs) and key visual features extracted from swimmer tracking. Each includes:

60 IMU features (3-axis accelerometer & gyroscope data from 10 sensors)

Head position coordinates (head_x, head_y) derived from video frames

Stroke start probability (stroke_prob)

Stroke type labels: Butterfly, Backstroke, Breaststroke, Front Crawl, and Freestyle
